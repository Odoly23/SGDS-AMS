# SGDS-AMS

Repo ini berisi dua proyek Django yang terpisah:

- [`lafex/`](lafex/README.md): **LAFEX (Lafaek Exploration)**, aplikasi belajar bahasa Timor-Leste (mobile first, PWA, suara, karakter AI, crowdsource).
- [`timor_ai/`](timor_ai/README.md): **LAFEX-AI**, chatbot/penerjemah bahasa daerah berbasis RAG + LoRA dengan poin prabayar.
